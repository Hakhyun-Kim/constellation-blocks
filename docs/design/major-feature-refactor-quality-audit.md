# 대형 기능 정리·품질 감사 — 고정 영웅단/별자리 원정

- 기준일: 2026-08-11
- 범위: 랜덤 소환·조합 중심 방어 게임을, 이름 있는 영웅단·별자리 원정·실시간 3매치 전술 루프로 바꾼 변경
- 상태: 이번 변경의 구현 전 감산 감사와 구현 후 품질 패스를 기록함

## 1. 구현 전 감산 감사

| 영역 | 현재 프로덕션 경로 | 이전 경로의 판정 | 이유와 후속 |
|---|---|---|---|
| 시작/전투 | `createGame()`의 고정 영웅단과 `journey` | 유지 | 기본 생성은 `squad: true`, 루나도 별도 챔피언이 아니다. 엔진 검사로 고정한다. |
| 영웅 성장 | 레벨·XP·전문화 (`src/engine/squad.js`) | 유지 | 명명된 영웅의 지속 성장이라는 현재 루프의 단일 출처다. |
| 소환/조합/판매 | 공개 UI와 고정 영웅단 입력에서는 도달 불가 | 호환성·테스트용 격리 | `fixedSquad:false`의 옛 저장 복원과 결정적 엔진 fixture가 남아 있다. 현 기능에서 삭제하면 저장 호환과 넓은 엔진 검사를 동시에 흔든다. 다음 별도 마이그레이션에서 `legacy` 모듈/fixture로 분리하거나, 지원 기간을 공지한 뒤 제거한다. 책임: 프로젝트 유지보수자. |
| 별지기/외형/기술 | `state.squad`에서는 생성하지 않음 | 호환성·테스트용 격리 | `state.champ`는 레거시 상태에서만 만든다. 새 루프에서는 루나가 영웅 카드로 존재한다. |
| 카피/조작 | 고정 영웅단·여정·전술판 | 제거됨/갱신됨 | 소환 버튼과 판매 바는 공개 화면에서 숨기고, 단축키도 고정 영웅단에서는 성장 탭으로만 연결한다. |

**경계:** 이번 변경에서는 저장 포맷과 기존 순수 엔진 fixture를 깨지 않는다. 대신 카드 표시 로직을 `src/app/hero-card.js`로 분리해, 현재 프로덕션 UI가 옛 조합 카드 마크업에 다시 의존하지 않게 했다.

## 2. 구현 후 품질 패스

| 확인 항목 | 적용한 개선 | 확인 방법 |
|---|---|---|
| 영웅 식별 | 영웅별 절차적 별자리 초상, 역할, 고유 기술, 피해/DPS/사거리, 레벨·XP·전문화 포인트를 한 카드에 표시 | 데스크톱 2열, 좁은 화면 1열 CSS와 키보드/포커스 라벨 |
| 정보 위계 | 이름/역할 → 고유 전술 → 즉시 비교할 전투 수치 → 성장 순서로 배치 | 카드 선택과 툴팁의 상세 수치는 기존 엔진 수정자와 같은 값을 사용 |
| 모션 범위 | 카드 상호작용은 카드만 2px 이동하고, 선택 테두리/XP 바만 갱신 | 전체 화면 플래시를 새로 추가하지 않음; `prefers-reduced-motion`의 기존 게임 정책을 유지 |
| 성능/에셋 | CSS 그라디언트·기호만 사용하고 이미지·오디오·3D 모델을 추가하지 않음 | 번들 빌드와 기존 엔진/전술 검사 |

## 3. 이번 출고의 검증

실행 결과는 이 변경을 마친 뒤의 커밋 기록에 다음 세 게이트로 남긴다.

```powershell
npm.cmd run engine:check
npm.cmd run tactics:check
node scripts/balance-check.mjs 60
npm.cmd run build
```

브라우저 수동 스모크는 첫 여정 진입, 영웅 카드 선택, 영웅 성장 포인트 선택, 첫 전술 스왑, 좁은 화면 카드 1열을 확인한다. 외부 브라우저 제어가 불가능한 환경에서는 이 항목을 실행하지 않은 검증으로 명확히 남긴다.
